# Fluency Forge — Daily B1→C1 English Practice

A comprehensive, self-contained English practice web application tailored for B1→C1 learners with a modern study aesthetic (Notion + Duolingo energy) and paper-first philosophy.

## ✨ Highlights
- **7 Research-Backed Fluency Techniques**:
  1. *Say It Without Saying It*: 30 B1–C1 circumlocution targets with 60s timer & collocations.
  2. *Describe a Picture in 60s*: 16 evocative visual scene prompts + image upload support.
  3. *Three Random Words, One Story*: 55-word curated pool with live keyword detection.
  4. *Collocations & Sentence Frames*: 52 native phrasal frames, pitfall corrections & 3-sentence production.
  5. *Cover & Recall (Che Lại và Tự Nói)*: 10 authentic passages with 30s read phase and chunk comparison.
  6. *Retrieval Practice (SRS)*: 40 target cards powered by SM-2 spaced repetition with 3D flip cards.
  7. *Story Retelling (4-3-2)*: Paul Nation's fluency formula (4 min → 3 min → 2 min) with narrator and tone toggles.
- **Paper-First Mode**: One-click printable worksheets with dedicated notebook prompts and `@media print` styling.
- **Modern Study Aesthetic**: Clean white canvas, bold dark typography, and strategic neon & pastel highlights (#FFE500, #39FF14, #FFB3C6, #C9B8FF, #A8D8FF).
- **Web Audio Chimes**: Melodic synthesizer chimes on timer completion (100% offline).
- **Persistence**: Habit streak tracker, 30-day consistency heatmap, and JSON backup export/import.

## 🚀 Getting Started
Simply open `index.html` in any modern web browser. No build steps or server required.
